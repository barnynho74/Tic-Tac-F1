# 🏁 Formula 1 Tic-Tac-Toe

An interactive web game that combines classic **Tic-Tac-Toe** with the rich history of **Formula 1**!  
Players compete using their knowledge of F1 drivers, teams, and nationalities to claim squares on the board.

## 🎮 How the Game Works

Formula 1 Tic-Tac-Toe is a two-player game where every move requires entering a valid Formula 1 driver that matches the given criteria.

### Rules:
- At the start, players select:
  - **3 teams** for the left side (rows)
  - **3 teams** for the top side (columns)
- Each square represents a combination of:
  - A left-side team
  - A top-side team
- To claim a square, you must correctly enter the name of a driver who meets **both criteria**
- If the answer is correct → the square is claimed by the player
- If the answer is incorrect → the turn is lost
- The goal is to get **3 in a row** (horizontally, vertically, or diagonally)

## ⚙️ Features

- Large database of historical and modern F1 drivers (up to 2025 season)
- Autocomplete driver search  
- Local multiplayer (Player 1 vs Player 2)  
- Multiple difficulty levels (Easy, Medium, Hard, Extreme)  
- Built-in score tracking  
- New game setup and random selection options
